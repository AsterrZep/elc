# M1 — Modelo + editor 2D mínimo

- **Estado:** completado (demo visual pendiente de revisión manual)
- **Fecha:** 2026-11-26
- **Requisitos de la puerta:** `REQ-GEO-001/005/006`, `REQ-IO-002/004`, `REQ-UX-004/009`

## Qué se entregó

| Pieza | Dónde |
| --- | --- |
| Cámara mm↔px, pan, zoom anclado al cursor, encuadre, calibración de fondo | `crates/elec-edit/src/camera.rs` |
| Snap a extremos (rstar), ortogonal y rejilla, con prioridad extremo > ángulo > rejilla | `crates/elec-edit/src/snap.rs` |
| Historial por snapshots, rama de redo, huella FNV del proyecto | `crates/elec-edit/src/history.rs` |
| Comandos `AddWall`, `AddRoom`, `AddDevice`, `AddOpening` con validación mínima | `crates/elec-edit/src/commands.rs` |
| `Session`: documento + cámara + selección + índice + hit-test (dispositivo > muro > habitación) | `crates/elec-edit/src/session.rs` |
| Ventana eframe, barra de herramientas, lienzo, atajos Ctrl+Z / Ctrl+Shift+Z / Ctrl+S | `crates/elec-app/src/main.rs` |
| Guardar/cargar JSON con migraciones, encuadrar, `--smoke` sin ventana | `crates/elec-app/src/main.rs` |

## Límites conocidos de M1

- La demo de la puerta (baño + cocina + 2 dormitorios + 8 dispositivos, guardar y reabrir) no se
  ha hecho todavía a mano: la app arranca y guarda, pero no hay captura ni revisión visual.
- Las aberturas se colocan con medidas fijas (puerta 900 mm, ventana 1200 mm) a partir del clic;
  arrastrarlas y editar sus cotas llega en M2.
- No hay borrar ni mover elementos: undo/redo y añadir es todo el vocabulario de edición de M1.
- La calibración de plano de fondo existe en `Camera::calibrate` y está probada, pero aún no tiene
  botón en la UI ni carga de imagen.
